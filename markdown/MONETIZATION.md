# MONETIZATION.md — Free-First Student Access & Sustainability Model

---

## 1. Core Student-First Pledge

ResumeIQ is built **free-first** for college students, fresh graduates, and entry-level job seekers. **No payments, checkout flows, or subscription gates are implemented in v1**, and essential career-readiness utilities must never sit behind artificial paywalls.

---

## 2. Always-Free Core Capabilities

Every user has unrestricted access to:
1. **Student Resume Builder** (core ATS-safe editorial templates + live preview + PDF export).
2. **PDF & DOCX Upload & Parsing** (including editable extraction verification).
3. **Full 100-Point Resume Quality Analysis** with complete rubric evidence & deductions.
4. **ATS Compatibility Estimate** & layout/formatting diagnostics.
5. **Role-Based Skill Matching** (core 4 target roles: *Data Analyst*, *Web Developer*, *AI Engineer*, *Cloud Engineer*) + standard Custom Job Description extraction.
6. **Prioritized Smart Feedback** & template-based bullet-writing guidance.
7. **PDF Audit Report Export** & recent local-workspace version tracking.

---

## 3. Ethical Post-MVP Premium / Campus Licensing Ideas (Deferred)

Only after product stability and student validation:
- **University / Placement Cell Bulk Cohorts:** Campus-wide anonymized readiness analytics for college placement offices (supporting free individual student access).
- **Extended Design Templates & Custom Branded Audit Reports.**
- **High-Cost Hosted GPU / External LLM Rewrite Quotas:** If optional hosted inference incurs real per-token server costs, metered usage or bring-your-own-key options prevent unsustainable burn while keeping local deterministic analysis free forever.

**Anti-Pattern Guardrail:** Never degrade free resume scoring accuracy or hide critical parsing warnings to upsell a paid tier.
