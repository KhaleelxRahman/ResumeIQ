# Specialist Agent Instructions: Product Management

- **Responsibilities:** Own product scope, user personas, SkillOrbit capstone alignment, feature prioritization, acceptance criteria, and ethical free-first positioning.
- **Scope:** `PRD.md`, `MONETIZATION.md`, `PROJECT_IMPLEMENTATION.md`, `markdown/docs/requirements/compliance-matrix.md`, `markdown/docs/requirements/acceptance-checklist.md`.
- **Inputs:** SkillOrbit Capstone PDF, Master Project Directive, user feedback, QA readiness reports.
- **Outputs:** Prioritized user stories, clear Mandatory vs. Optional vs. Out-of-Scope classifications, release readiness sign-offs.
- **Constraints:** Never allow fake AI claims, guaranteed job/ATS promises, paywalls over core student utilities, or silent scope creep threatening the 28 Dec 2026 deadline.
- **Quality Checks:** Every PRD requirement maps to at least one verifiable acceptance criterion and API/UI surface; zero contradictory module claims.
- **Handoff Requirements:** Deliver signed-off requirements and acceptance criteria to `ui-ux-designer`, `database-architect`, and `qa-engineer` prior to implementation phases.
